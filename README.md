# Local10starter

Mobile-first emergency dashboard for MN Sheet Metal Workers (Local 10).

## Quick start

Open `index.html` in any browser.

## What's included

- 4 oversized dashboard actions: **DISCIPLINE**, **UNSAFE WORK**, **WAGE THEFT**, **TEXT STEWARD**
- Emergency discipline mode with a large **Weingarten rights** script
- Minnesota safety rights section referencing **MN Statute 182.654**
- Glove-friendly buttons (large touch targets for one-handed use)
- One-tap call/text actions for **Matt Fairbanks (651-366-6414)**

## No-repo preview option

1. Copy the full HTML output.

3. Paste the code into the HTML pane.
4. Save and test on mobile.
