# Local 10 Starter

Union workers' hub for SMART Local 10 (Minnesota Sheet Metal Workers).

## What's Here

```
index.html        ← Union emergency dashboard (open in any browser)
manifest.json     ← PWA config so it can be saved to your home screen
notes/
  thinking.md     ← Personal thinking / brainstorm notes
  game-design.md  ← Game design ideas and plans
  union.md        ← Union info, contacts, meeting notes
```

## How to Use

- **Union site**: Open `index.html` on your phone or share the link. Works offline.
- **Notes**: Open any file in `notes/` and paste whatever you want in there. They're yours.
