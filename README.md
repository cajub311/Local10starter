# Local10 Starter

Clean, simple repo layout focused on your union site, with extra notes split into
separate files so things stay easy to manage.

## Repository layout

- `union-site/index.html` - main union site page
- `notes/thinking.md` - scratchpad for planning/thoughts
- `notes/game-design.md` - game design notes
- `notes/union-stuff.md` - union-specific notes to keep handy

## Quick start

Open `union-site/index.html` in a browser to view the site.

You can copy/paste content from the note files into the site whenever you are
ready.
