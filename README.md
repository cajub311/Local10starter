# SMWIA Local 10 — Worker Emergency Dashboard

A mobile-first, single-page emergency tool for **MN Sheet Metal Workers (Local 10)**.  
Designed for one-handed use on the factory floor — with gloves on, screen cracked, no time to waste.

## Features

- **4 Emergency Buttons** — DISCIPLINE, UNSAFE WORK, WAGE THEFT, TEXT STEWARD
- **Weingarten Rights Script** — Read it word-for-word to management in giant bold text
- **MN Statute 182.654** — Your legal right to refuse unsafe work
- **MN Statute 181.101** — Wage protection / wage theft reporting
- **One-Handed Design** — Every button is at least 56px tall for gloved or dirty hands
- **Instant Contact** — Call or text Matt Fairbanks (651-366-6414), OSHA, MN Dept of Labor
- **Copy-to-Clipboard** — Copy any rights script with one tap
- **No dependencies** — Pure HTML/CSS/JS, works offline, no build step

## How to Use

### Option A: Open directly
Double-click `index.html` in any browser. That's it.

### Option B: CodePen / JSFiddle
Copy the contents of `index.html` and paste into the HTML panel at [codepen.io](https://codepen.io) or [jsfiddle.net](https://jsfiddle.net).

### Option C: Host for free
Push this repo to GitHub and enable **GitHub Pages** (Settings → Pages → Source: main).  
Your dashboard will be live at `https://<username>.github.io/<repo>/`.
